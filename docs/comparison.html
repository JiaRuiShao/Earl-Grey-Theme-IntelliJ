Known differences IntelliJ cannot express

  • Packages (java.util.): IntelliJ highlights package names with the class name key (HighlightNamesUtil.highlightPackage), so they share the class color. VS Code paints namespaces #886A44.
  • Enum constants: IntelliJ treats them as static final fields; VS Code gives the enumMember token the class style (#605A52 italic). The scheme keeps static final fields correct.
  • true/false/null, super(...), instanceof, var, when: one JAVA_KEYWORD key in IntelliJ, several TextMate scopes in VS Code.
  • ->, ::, @, ... and string quote marks have no attributes key of their own in IntelliJ.
  • Bracket pair colorization is an editor feature in VS Code (on by default). IntelliJ needs the Rainbow Brackets (Lite) plugin; the scheme ships its color keys.
